# 怀旧游戏收纳盒 · games-case

微信小游戏「怀旧游戏收纳盒」的素材与工程仓库。当前收录两部分内容：**微信小游戏后台用的通用素材封面（含生成脚本）** 与 **游戏实机截图**。

> 说明：小游戏的运行时代码不在本机，本仓库暂只托管素材资源与生成脚本；拿到工程后可在此追加 `miniprogram/` 目录。

| 项目 | 要求 | 定稿实测 |
| --- | --- | --- |
| 尺寸 | 650 × 250 px | 650 × 250 px |
| 格式 | JPG / JPEG | JPEG（RGB） |
| 体积 | ≤ 80 KB | 74,496 字节（72.8 KB） |
| 内容 | 不放图标与游戏名 | 纯场景插画，无文字无水印 |

## 重新生成

依赖 Python 3 + Pillow：

```bash
pip install pillow
python wx-material/scripts/make_final.py
```

脚本流程：从 `raw/` 的 3:2 原图按 **2.6:1** 裁横带 → 两步 Lanczos 降采样 + UnsharpMask 保锐度 → 椭圆暗角收拢视线 → 二分 JPEG quality，命中 80KB 上限。

换图只需把新原图放进 `raw/`，改脚本里的 `SRC` / `RECT`（裁剪框）后重跑；`RECT` 已避开原图右下角的生成水印。

## 设计调性

实机界面为**扁平矢量 + 深色底**：背景深靛蓝、台球桌绿绒、按钮与力度条用红橙点缀，整体极简、无纹理。封面插画走的是复古街机氛围路线，与实机风格存在差异——若要统一，建议按实机的扁平配色再出一版。
